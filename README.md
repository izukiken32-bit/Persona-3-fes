# Persona 3 FES — Android project

Native Android launcher/build scaffold for a future Persona 3 FES runtime integration.

## Current status
- Android launcher UI and local settings
- Device profile label for itel City 100 / Android 14
- GitHub Actions debug APK build

**Not yet a playable game port:** no game runtime or game assets are included. A compatible runtime and legally obtained game files must be integrated separately. Preferences currently save locally and do not affect a game engine.

Build from GitHub Actions → **Build Persona 3 FES Android APK** → Run workflow. The successful run publishes an APK artifact.
