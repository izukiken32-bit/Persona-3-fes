# Persona 3 FES — Android project
Native Android launcher and early engine foundation targeting ARM Mali GPU devices through a future native-recompilation/runtime port.

## Current status
- Android launcher/settings and CI APK workflow
- NDK/CMake shared-library target
- Early EE CPU/RAM core slice and JNI runtime probe

**Not playable yet.** The CPU bring-up code is incomplete and cannot boot the game. See ENGINE_STATUS.md for the remaining engine roadmap. No game data is included; users provide their own legally obtained files.
